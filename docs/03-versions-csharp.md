# Nouveautés C# (v2 → v13)

Ce document résume l'évolution des versions de C# et leur correspondance avec le Framework .NET / .NET Core / .NET moderne.

## Historique des versions majeures

- **C# 10 / .NET 6** : Introduction des types record struct, file-scoped namespaces, global using directives.
- **C# 11 / .NET 7** : Raw string literals, generic math support, required members.
- **C# 12 / .NET 8** : Primary constructors pour toutes les classes/structs, collection expressions, interceptors.
- **C# 13 / .NET 9** : Améliorations sur les verrous (lock object), nouvelles fonctionnalités de pattern matching et performances accrues.
